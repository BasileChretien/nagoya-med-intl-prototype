GAMEは、医学教育と医学研究を発展させるための国際学術アライアンスです。2017年に、香港中文大学の医学部長の呼びかけで、9つの大学の医学部が共同で設立しました。医学部だけが集まり、それぞれが共同事業を1つずつ担当します。名古屋大学は設立時から加盟しています。名古屋大学では、粕谷英樹とイッツェル・ブストスが中心になって活動しています。GAMEには独自のサイト（[game-med.net](https://www.game-med.net)）もあります。

## 加盟校

2020年にアルバータ大学が脱退したため、加盟校は名古屋大学と下に挙げる7校の、合わせて8校です。

## 主要プロジェクト

プロジェクトは、加盟校が1つずつ担当しています。

| プロジェクト | 担当校 |
| --- | --- |
| 磁気共鳴画像（MRI）コンソーシアムの構築 | ノッティンガム大学 |
| 予防老年医学の研究ネットワークの構築 | モナシュ大学 |
| Healthy Start Network | エラスムス医療センター |
| レビー小体病のリスク集団に関する国際共同研究 | 名古屋大学 |
| 民族と地域をまたぐ腸内細菌叢の国際研究ネットワーク | 香港中文大学 |
| 薬物性肝障害研究の国際ネットワーク | ミュンヘン大学 |
| International Online Barrett's Esophagus Registry（IOBER） | ボローニャ大学 |
| Transnational Educational Initiative（TEI） | 高麗大学 |

このほかにPhD4GAMEがあります。加盟校間の研究を、共同の博士教育で後押しする取り組みで、2校または3校の間での交流に重点を置いています。

## 学生向けの活動

**TEIサマーキャンプ**は、高麗大学が主導するTEIの活動で、主に医学生と大学院生が対象です。加盟校が毎年サマーキャンプを開いています。第1回は2019年に名古屋大学が主催しました。7大学から18名の学生が参加し、5日間にわたり災害医療と医師のプロフェッショナリズムを学びました。福島への1泊2日の訪問も行いました。第2回は2020年にボローニャ大学で、第3回は2021年にモナシュ大学で開かれ、第3回は7月26日から29日のオンライン開催でした。

**オンライン症例討論**は、TEIの活動の一環として2020年11月と12月に始まりました。加盟校の高学年の医学生が集まります。学生は教員の指導を受けながら症例を発表し、国ごとの保健制度や医療保険の違いも学びます。第2回は2021年5月25日から6月29日まで、毎週火曜日に開かれました。香港中文大学、高麗大学、ミュンヘン大学、モナシュ大学、名古屋大学が運営し、ボローニャ大学がゲストで加わりました。6大学から23名の学生が参加しました。第3回は、2022年5月24日から7月5日に全7回で行う予定でした。参加は無料で、修了時に参加証明書が出ます。

## 年次総会

年次総会は、加盟校が持ち回りで開催します。第6回は2022年11月3日と4日に名古屋大学が主催しました。3年ぶりの対面開催で、各校から20名を超える代表者が集まりました。

## 現在の状況

医学部のページに載っている最新のGAMEの行事は、2022年11月に名古屋大学が主催した年次総会です。2023年から2026年に名古屋大学で開いた総会、キャンプ、症例討論の記録はなく、次の行事の予告もありません。加盟校のうちモナシュ大学とノッティンガム大学の関係者は、2024年3月に名古屋大学を訪れています（[来訪の受け入れ](visits)）。現在の予定は国際連携室にお尋ねください。

## 参加するには

GAMEに加盟できるのは医学部だけです。新しい大学が加盟する方法は、旧ページに書かれていません。プロジェクトに参加したい医学部や、名古屋大学のプロジェクト担当者に連絡したい方は、国際連携室にご連絡ください。

## 問い合わせ

名古屋大学でのGAMEに関する問い合わせは、[問い合わせ](../about/contact)のページから国際連携室にお送りください。
