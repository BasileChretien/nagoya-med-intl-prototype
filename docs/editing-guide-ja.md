# 国際交流サイトの編集ガイド

このガイドでは、国際交流のサイトを直す方法を説明します。作業はブラウザーだけでできます。ソフトを入れる必要はありません。

## 編集ページで直せるもの

編集ページで直せるのは、次の4つです。

- お知らせ・イベント（追加もできます）
- プログラムの締切、定員、応募の方法など
- 連絡先のメール、電話、場所
- ページの題名、説明、本文

写真や新しいページ、協定校、体験記は編集ページでは直せません。技術担当に頼んでください。

## 1. 編集ページを開く

次のアドレスを開きます。ブラウザーのブックマークに入れておくと便利です。

https://basilechretien.github.io/nagoya-med-intl-prototype/admin/

サイトを大学のサーバーに移した後は、アドレスが変わります。新しいアドレスは技術担当が知らせます。

画面の言葉は、ブラウザーの言語に合わせて変わります。英語で出るときは、ブラウザーの言語を日本語にしてください。

## 2. サインインする

1. 管理者から受け取ったユーザー名とパスワードを入れます。
2. 「サインイン」を押します。
3. 初めてのときは、自分のパスワードを決めます。12文字以上にします。

パスワードを忘れたときは、管理者に再発行を頼んでください。

## 3. 締切を変える

1. 左の一覧で「プログラム / Programmes」を選びます。
2. 直したいプログラムを選びます。
3. 「締切 / Deadline」の「状態」を選びます。受付中・随時・未発表・締切の4つから選べます。
4. 締切日が決まっているときは、「締切日」に日付を入れます。
5. 「締切の説明」を、日本語と英語の両方で直します。
6. 公式のページと見比べたときは、「確認した日」を今日の日付にします。
7. 「保存」を押します。

日付や人数などの数字は、日本語と英語で同じにしてください。数字が違うと、サイトの更新が止まります。

締切日を過ぎた「受付中」は、サイトでは自動で「締切」と表示されます。それでも状態と説明は直してください。

## 4. お知らせを追加する

1. 左の一覧で「お知らせ・イベント / News」を選びます。
2. 新しい項目を作るボタン（「新規」または「New」）を押します。
3. 日付と種類を選びます。種類はお知らせ、イベント、募集の3つです。
4. 見出しと要約を、日本語と英語の両方で書きます。
5. 全文を載せたいときは、「本文」に印を付けて書きます。段落の間は1行あけます。
6. 詳しいページがあるときは、そのアドレスを入れます。「https://」で始まるアドレスにします。
7. 「保存」を押します。

番号は自動で付きます。お知らせはサイトで日付の新しい順に並ぶので、並べ替えは要りません。

## 5. ページの誤字を直す

1. 左の一覧で、ページのある分類を選びます。たとえば「ページ：海外で学ぶ」です。
2. 直したいページを選びます。
3. 画面の上で、日本語と英語を切り替えられます。
4. 「本文」の誤字を直します。
5. 英語のページにも同じ間違いがないか確かめます。
6. 「保存」を押します。

本文は、Markdownという書き方で書かれています。次の記号は表示の形を決めています。消したり動かしたりしないでください。

| 記号 | 役目 |
| --- | --- |
| `\|` | 表の区切りです。 |
| `**` | 間の文字を太字にします。 |
| `[ ]( )` | リンクです。[ ]の中が見える文字で、( )の中がリンク先です。 |
| `#` | 行の初めにあると見出しになります。 |
| `-` | 行の初めにあると箇条書きになります。 |

## 6. 保存した後に起きること

保存すると、変更はすぐに記録されます。続いて、自動のチェックが始まります。問題がなければ、数分でサイトが新しくなります。

保存した内容は、日本語と英語が同じことを言っている、という扱いになります。保存の前に、両方の言語を読んで確かめてください。

保存した内容が間違っていたときは、もう一度直して保存します。前の版はすべて残っているので、技術担当が元に戻すこともできます。

## 7. サイトが変わらないとき

1. 10分ほど待ちます。
2. サイトのページを再読み込みします。「Ctrl」キーを押しながら「F5」キーを押します。
3. それでも変わらないときは、チェックで止まっています。前の内容がそのまま表示されています。
4. 直した日時と項目を、技術担当に伝えてください。

チェックで止まる主な理由は、次のとおりです。

- 数字が日本語と英語で違う
- 日本語か英語の片方が空になっている
- 「確認した日」が今日より後になっている
- 新しい英語の略語（大文字だけの言葉）を使った。略語は、意味を書いた一覧に載せる必要があります。

チェックの結果は、GitHubの「Actions」の画面で見られます。赤い印がチェックで止まった更新です。

https://github.com/BasileChretien/nagoya-med-intl-prototype/actions

## 8. 気をつけること

- 同じ項目を2人で同時に直さないでください。
- 個人のメールアドレスは載せません。窓口のアドレスを使います。
- 「ファイル」や「アセット」から写真を上げないでください。写真には説明文が要るので、技術担当に頼みます。
